# Что мне нужно?

1. Сохранение конфигов локально
Некоторые устройста (ноуты, пк, телефоны) не имеют ssh. Я хочу сохранить результат работы локально (там, где выполнился плейбук). Чтобы потом передать эти конфиги на стройства

2. Идемпотентность
Если она есть, то это уже хорошо
Если её нет, то я хочу, чтобы если плейбук был уже запущен, то он не перегенерировал ключи для устройств

3. Пост-квант
Я хочу, чтобы генерировались PSK. Pre-shared keys
Возможно, я не разобрался в том, как это сделать, но документации я по этому не нашёл

4. Документация
Документация к проекту должна быть в формате markdown файлов, чтобы её можно было засунуть во фронтэнд на астро, чтобы был поиск по словам и т.д.

5. Роутинг
Здесь я тоже могу ошибаться, но я хочу настраивать роутинг (какие адреса доступны устройству) через переменные для ansible (host или group).
Для роутинга устройств, которые настраиваются через конфиги без ссш я хочу настраивать это отдельно через переменные
